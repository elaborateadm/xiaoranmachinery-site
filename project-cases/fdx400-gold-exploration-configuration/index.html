Configuring an FDX400 for 400 m NTW gold exploration in mountain terrain

A typical mid-depth core exploration program: how we narrow down the rig configuration from "around 400 m NTW" to a shippable, working machine — and what the buyer should confirm first.

The starting conditions

  • Target depth: 300–400 m finished holes, NTW core size preferred for assay quality
  • Terrain: mountainous site reached by 4×4 tracks; machine must self-travel between pads
  • Geology: mixed overburden then hard rock; mud circulation required below the water table
  • Logistics: destination port known, site accessible by road container truck to the nearest transfer point

Why the FDX400 fits — and where the checks matter

RequirementFDX400 reference valueWhat to confirm on site
Depth capacity480 m BTW / 400 m NTWKeep ~20% margin below rated depth for rod changes and complex formations
MobilityRubber-track crawler, 30° gradeabilityConfirm steepest pad access slope and rutted ground sections
PowerWater-cooled diesel, Quanchai engineFuel supply on site; cold-start requirements at altitude
CirculationBW90 mud pump standardWater source distance; whether a second pump or larger tank is needed
Mast & angle45–90° drilling angle, 7 m mastPad size for mast raise and rod handling
Depth ratings are configuration references, not a guarantee for every formation. Rod string, pump, winch and site access decide the real output — read our NTW, BTW and HTW depth guide and the rig selection guide for the full method.

What gets written down before production

  1. Machine parameters and optional equipment (feed stroke, hydraulic clamp, winch capacity)
  2. Consumables plan: rod string quantity, core bits, mud materials for the first campaign
  3. Packing and transport plan — see our container packing walkthrough
  4. Spare-parts and training plan for the crew
