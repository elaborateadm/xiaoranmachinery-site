Improving Core Recovery Rate in Fractured Formations

Why core recovery drops in fractured, weathered and sheared ground, and the barrel, bit, run-length and fluid changes that bring the rate back up.

Published November 26, 2026

Core recovery rate is the share of a drilled interval that reaches the core box intact. In competent rock it is rarely the problem; in sheared, weathered or broken ground it becomes the number that decides whether a hole can be used for a resource estimate at all. Improving it is mostly a matter of matching barrel, bit, run length and fluid to the formation — and then measuring the result honestly.

What the recovery figures actually measure

Recovery is usually reported three ways. Total core recovery (TCR) counts everything recovered as a percentage of the run; solid core recovery (SCR) counts only full-diameter cylindrical pieces; and rock quality designation (RQD) counts only pieces longer than twice the core diameter. A run can post 100% TCR and a poor RQD at the same time, because broken rubble fills the barrel volume without any of it being usable core. Record all three, and note the depth of each loss rather than averaging it away — a single weak zone is exactly what the geologist needs to see.

Where recovery is lost, by formation

Loss has a different cause in each ground condition, so the fix changes too. The table below maps the common failure mode to the first correction to try before anything else is changed.

FormationTypical loss mechanismFirst fix
Sheared or clay-rich zoneSoft core grinds or washes out in the barrelShorter runs, slower rotation, split inner tube
Highly fractured hard rockBlocks jam the barrel and abrade each otherTriple-tube barrel, reduced fluid volume
Strongly weathered rockMaterial returns as sludgeCore lifter and catcher, controlled feed
Running sand or gravelLoose material never enters the barrelCasing or liner ahead of the bit
Soluble or swelling groundHole closure squeezes the coreMatched drilling fluid, casing plan
Steeply dipping beddingCore breaks along planes and dropsShorter runs, reduced bit load

More than one mechanism is usually active in the same hole. Fix the largest loss interval first and measure the change before adding more changes.

Barrel and bit choices that protect core

The single most effective upgrade in broken ground is a triple-tube, or core-splitting, barrel. The third tube holds the core steady so it is not re-ground during the run, and the split design lets the core be lifted out without being pushed through the barrel. Inner-tube liners and a correctly sized core lifter or catcher do the rest: they keep loose material in the tube on the way up rather than letting it slide back into the hole.

Bit choice is the second lever. An impregnated bit suited to the rock’s hardness cuts steadily and keeps the load on the formation low; a bit run too hard generates vibration that shakes loose core apart. Whichever method is in use, the time the hole stands open matters: wireline coring reduces that open time by retrieving the inner tube through the rods, which often helps in unstable ground. The barrel, lifter and bit must all match the rod size, so decide the core size first — see how BTW, NTW and HTW depths compare before committing.

Run length, feed and fluid: the technique side

Half of recovery is hardware and half is technique. Shorten the run before you change the barrel: a shorter run leaves less core to be disturbed and is easier to retrieve intact, even though it costs more rod handling. Keep the feed steady and avoid the pressure spikes that break core, and hold rotation speed to what the bit and the formation allow rather than what the rig can deliver. Fluid volume is the most common oversight — too much pump output erodes soft core and flushes fine material, so match circulation to the hole and to the zone being drilled.

The rig side is mostly about control. A machine with smooth, adjustable feed and pullback lets the driller hold a consistent load through a broken zone; a rig that only offers on/off feed makes recovery harder regardless of the barrel. Compare feed travel, pullback and rod-handling speed for the depth you plan, as in the FDX400 specification, and treat recovery control as a rig-selection criterion rather than an afterthought.

Recording recovery so the fix is visible

Improvement only shows up if the record is precise. Log TCR, SCR and RQD for every run, mark the depth of each loss, and note the barrel, bit and fluid used. Drill runs that compare like with like when you test a change, so a different bit is judged against the same formation rather than against a different part of the hole. Over a program, that record turns recovery from a complaint into a controlled variable — and it gives the geologist the interval detail that a single averaged number would hide.

Frequently asked questions

What core recovery rate is good enough?

It depends on what the core is for. For a resource estimate, the acceptable threshold is usually set by the project’s own standard rather than by a universal number, and it can differ between a wide mineralised zone and a narrow structure. Agree the target with the geologist before drilling, then log every run against it.

Does wireline coring improve recovery by itself?

Not by itself. Recovery depends mainly on the barrel, the bit, the fluid and the ground. Wireline helps by cutting the time the hole stands open between runs, which can reduce disturbance in broken ground, but a poorly matched barrel will lose core in either method.

Can I raise recovery without changing the rig?

Often, yes — shorter runs, a triple-tube barrel, a correct core lifter and a reduced fluid volume are technique and tooling changes. If the hole is deep enough that open time is the problem, that is when the rig’s winch and rod handling start to matter and a different configuration is worth comparing.
