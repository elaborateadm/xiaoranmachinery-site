Spider Crane vs Aerial Work Platform: Choose by the Job

Compare material lifting with personnel access using XZ03C, XZ05A, GTJZ10 and HC0607EA specifications and a practical site inquiry checklist.

Published October 4, 2026

Quick answer: Shortlist a spider crane for a defined material-lifting task, and a suitable aerial work platform for positioning people with tools at height. Required hook height, platform-floor height and working height are different measurements. A crane’s optional basket does not make the equipment automatically interchangeable with a personnel platform.

Start with the task, rather than a height label

Different jobs need different selection information
QuestionMaterial liftingPersonnel access
What must reach the work position?A suspended load and its lifting gearPeople, tools and permitted materials on a platform
Which height is relevant?Required hook height and load pathPlatform-floor elevation and actual work position
Which load information is needed?Total suspended load and chart capacity at the planned radiusPlatform load, occupants, extension-deck limit and distribution
Which site measurements matter?Access route, setup footprint and ground supportAccess route, supporting surface, obstacles and operating envelope

For a glass or steel installation, describe separately how the panel will be lifted and where the installers must stand. A project may need distinct equipment for the two tasks. A common work location does not establish a common permitted use.

Read the listed crane heights correctly

XZ03C lists 12.5 m maximum lift height with a 3,000 kg rated-load class. XZ05A lists 17 m maximum lift height with a 5,000 kg rated-load class. Neither description gives the allowed load at an arbitrary work position. Request the load chart for the actual radius, boom setup and accessory configuration.

These crane pages list a rotating work basket as an option. Before considering personnel use, obtain written confirmation of the complete approved configuration and applicable requirements. US construction crane personnel hoisting has separate conditions under OSHA 1926.1431; do not treat an accessory listing as proof of suitability or regulatory approval.

GTJZ10 lists 320 kg safe working load; HC0607EA lists 250 kg rated load. Include occupants, tools and materials when checking the platform load. The extension deck limit is separate and does not increase the total platform rating.

A request such as “work at 10 metres” is incomplete. State whether 10 m refers to the platform floor or the task itself, and identify any horizontal obstruction. Use our height comparison guide to prepare the site measurements.

Check the route and the supporting surface

GTJZ10 lists a folded transport size of 2.48 × 1.15 × 1.97 m. HC0607EA lists 2.02 m overall length with ladder, 2.06 m height with rails folded and two stated width figures, 1.47 m / 1.30 m. Ask which width and configuration apply to the proposed machine; a slash-separated brochure value should not be guessed into a site plan.

A crawler chassis, self-levelling description or gradeability figure is not a universal permission to operate on a slope. Select against the supplied equipment instructions. The IPAF MEWP selection checklist provides a useful framework for reviewing restrictions, height, outreach and materials.

Send one clear brief for the whole project

Specify material lifting, personnel access or both. Include required hook or platform height; horizontal position of the task; load or occupants and tools; access dimensions; supporting-surface information; work duration; power availability; and destination country. Attach site photos and a sketch showing obstacles.

Compare spider crane models for the lifting task and aerial work platforms for personnel access. Request drawings, configuration details, manuals and destination-specific documentation before confirming the order.
